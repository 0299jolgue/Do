# BoostMaker

Site estático que gera cinco imagens de progressão de pontos e grava o vídeo no navegador com a animação final.

## Arrancar na ShardCloud

- Repositório: `0299jolgue/Do`
- Branch: `main`
- Runtime: Node.js 18 ou superior
- Comando de arranque: `npm start` (ou `node server.js`)
- Porta: `80` por omissão; usa `PORT` se a plataforma definir essa variável

O servidor serve os ficheiros da raiz e dos diretórios de assets. Não precisa de dependências externas nem de variáveis secretas.
